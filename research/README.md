# Research

OSM research notes for Street Space Editor / lane tooling.

| Package | Scope |
|---------|--------|
| [lane-editor-tags/](./lane-editor-tags/) | Lane editor tags, project surveys, `:lanes` fixtures |
| [width-measurements/](./width-measurements/) | How `width`, `width:lanes`, buffers, and related widths are measured and how they interact |
